## Travail sur le TP3

Ce cours est consacré au travail sur le TP3. Profitez-en pour avancer vos attaques, implanter vos correctifs et compléter votre rapport. Le professeur circulera pour répondre à vos questions.

Consultez [l'énoncé du TP3](/tp/tp3) pour le détail des attentes et du barème.


## Liste de vérification

Avant la remise, assurez-vous que votre repo contient:

- [ ] Le fichier **rapport.md** avec, pour chaque attaque, toutes les étapes et les captures d'écran
  - [ ] Attaque 1: BD fuitée et mots de passe
  - [ ] Attaque 2: BD fuitée et encryption
  - [ ] Attaque 3: Injection SQL
- [ ] Le projet de l'application avec vos correctifs (commits)
  - [ ] Hachage avec bcrypt
  - [ ] Encryption avec AES
  - [ ] Élimination des injections SQL
- [ ] Pour chaque correctif, la preuve dans le rapport que l'attaque ne fonctionne plus

:::warning Attention
Si vous ne remettez pas le projet corrigé, ou si l'application remise n'est plus fonctionnelle, vous aurez 0 sur les correctifs. Refaites la [séquence de vérification post correctifs](/tp/tp3#vérification-post-correctifs) avant de remettre.
:::

:::tip
N'oubliez pas de passer votre rapport au correcteur (Antidote ou celui de Word): la qualité du français vaut 2 points.
:::
