## Injecter du SQL, c'est quoi?

Une injection SQL c'est quoi?
- une situation où l'utilisateur peut exécuter du SQL de son choix sur la BD
- PAS LE PROGRAMMEUR mais l'utilisateur, nooooooooooonnnnnnnnnnn
- parce que le programmeur a pris ce que l'utilisateur lui a donné et l'a mélangé sans faire attention 
avec son code.

Ressource: https://www.w3schools.com/sql/sql_injection.asp

## Pourquoi c'est encore fréquent et très dangereux

On pourrait croire que l'injection SQL est un problème du passé: il suffit de ne pas concaténer les données de l'utilisateur dans une requête. Pourtant, l'injection fait toujours partie du [Top 10 de l'OWASP](https://owasp.org/Top10/), le classement des risques les plus importants pour les applications web:
- beaucoup d'applications anciennes (*legacy*) n'ont jamais été corrigées
- une concaténation « pour aller vite » dans un rapport, un filtre ou un tri suffit
- le code généré par IA ou copié d'Internet contient parfois des requêtes concaténées

Et quand la faille est là, l'attaquant exécute ses propres commandes SQL sur la BD. Il est seulement limité par les **droits du compte** que l'application utilise pour se connecter (rappel de la rencontre 2.2): si l'application se connecte en administrateur, l'attaquant peut tout lire, tout modifier et tout supprimer. En bref, on est morts.

## Comment ça marche

Imaginons une requête SQL construite par concaténation:

```csharp
string query = "SELECT * FROM users WHERE username = '" + username + "'";
```

Si l'utilisateur entre `admin' OR '1'='1` comme nom d'utilisateur, la requête devient:

```sql
SELECT * FROM users WHERE username = 'admin' OR '1'='1'
```

Cette requête retourne **tous les utilisateurs** car `'1'='1'` est toujours vrai!

## Types d'injections SQL

### 1. Bypass d'authentification
Entrer `' OR '1'='1` dans un champ de login

### 2. Extraction de données
Utiliser `UNION SELECT` pour extraire des données d'autres tables

### 3. Modification de données
Utiliser `; UPDATE` ou `; DELETE` pour modifier la base de données

### 4. Destruction
Utiliser `; DROP TABLE` pour détruire des tables entières
